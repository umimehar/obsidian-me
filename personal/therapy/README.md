# Therapy

Relationship and couples work, run as structured sessions through the `couples-therapy` skill. Each session reads the last two logs before it opens, so continuity lives in these files rather than in any one conversation.

Names are initialized here — `U` and a partner initial. No full names, employers, or addresses.

## Structure

- `log/YYYY-MM-DD.md` — one file per session
- `tracking.md` — the named cycle, goals, standing agreements, session ledger, risk status
- `notes/` — intake write-up and anything freeform
