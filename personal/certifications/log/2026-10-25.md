## Exam topic: structured JSON output in CI

The question asked how Claude in CI returns a JSON structured result for a PR. The answer is a JSON Schema passed with `--json-schema`; the validated result lands in a field named `structured_output`. The same field name shows up on all three surfaces.

Headless mode (`claude -p`), from https://code.claude.com/docs/en/headless.md:

```bash
claude -p "Extract the main function names from auth.py" \
  --output-format json \
  --json-schema '{"type":"object","properties":{"functions":{"type":"array","items":{"type":"string"}}},"required":["functions"]}' \
  | jq '.structured_output'
```

`--output-format` takes `text` (default), `json`, or `stream-json`. If the run ends without valid output, `structured_output` is absent, so check for it before reading.

GitHub Action (`anthropics/claude-code-action@v1`), from the repo's `action.yml` and `docs/usage.md`: pass the schema in `claude_args`, then read the step output `structured_output` with `fromJSON()`.

```yaml
- id: analyze
  uses: anthropics/claude-code-action@v1
  with:
    anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
    prompt: "..."
    claude_args: |
      --json-schema '{"type":"object","properties":{"is_flaky":{"type":"boolean"},"confidence":{"type":"number"}},"required":["is_flaky"]}'
- if: fromJSON(steps.analyze.outputs.structured_output).is_flaky == true
  run: echo "${{ fromJSON(steps.analyze.outputs.structured_output).confidence }}"
```

Agent SDK, from https://code.claude.com/docs/en/agent-sdk/structured-outputs.md: `output_format` in Python, `outputFormat` in TypeScript, set to `{"type": "json_schema", "schema": schema}`. The final `ResultMessage` carries `structured_output`. A result subtype of `error_max_structured_output_retries` means no valid output after retries. Schemas are validated as JSON Schema draft 07.
